# Ferramentas locais

Esta pasta pode guardar uma cópia local do agente Playit.gg com o nome:

`playit-windows-x86_64-signed.exe`

O executável é ignorado pelo Git e não faz parte dos commits. O iniciador usa essa cópia apenas para restaurar `%LOCALAPPDATA%\PlayitGG\playit-windows-x86_64-signed.exe` quando necessário.

Não coloque aqui tokens, arquivos `playit.toml`, URLs de confirmação ou outros segredos.
